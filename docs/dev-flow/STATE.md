# BlueyGames Dev-Flow State

最後更新：2026-09-26

## 目標

製作適合 5–8 歲、可在平板與電腦瀏覽器遊玩的生活任務 PWA 私人原型。

## 階段

- [ ] S1 架構：本次採小型純前端 PWA，待正式產品化再補完整競品與授權評估。
- [ ] S2 相容性：已採零後端、零帳號設計；待 iPad Safari 實機驗證。
- [ ] S3 研究：沿用兒童介面的大目標、短步驟、溫和回饋原則；待兒童實測。
- [x] S4 建置：四個任務的可玩垂直切片已完成。
- [x] S5 基礎驗證：4/4 自動測試通過；桌面瀏覽器已完成一整關、答錯重試與完成畫面 sanity check，console 無錯誤。iPad Safari 實機仍待驗證。

## 已定案

- 遊戲：洗碗、客廳整理、市場跑腿、做蛋餅。
- 互動：每關四步、三選一、答錯可再試、沒有倒數或扣分。
- 裝置：PWA，可加入 iPad 主畫面，資料只存在 localStorage。
- 語音：使用瀏覽器內建繁體中文朗讀，可隨時關閉。
- 授權：使用者提供的布麗圖片僅作私人原型；公開或商業發布前更換成自有或授權角色。
