# 布麗的生活任務（私人原型）

給 5–8 歲兒童的四個生活小遊戲：洗碗、打掃、跑腿買東西、做蛋餅。採大圖示、繁體中文語音、無倒數、無失敗懲罰，完成進度只存在本機裝置。

線上版本：<https://freshrogerchang-dev.github.io/Bluey-game/>

網站由 GitHub Pages 直接從 `main` 分支根目錄發布。

## 啟動

在此資料夾執行：

```powershell
npm start
```

依終端機顯示的網址開啟。若只是快速查看，也可用任何靜態網站伺服器提供此資料夾。

## 測試

```powershell
npm test
```

## 素材與發布提醒

`assets/bluey.jpg` 來自使用者提供的圖片，只供私人原型使用。公開、散布或商業發布前，請換成自有或已授權角色與圖像。瀏覽器語音由裝置內建的 `zh-TW` 語音提供，不會上傳兒童資料。
