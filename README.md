# 布麗的生活任務（私人原型）

給 5–8 歲兒童的八個 3D 生活小遊戲：做蛋餅、洗碗、整理客廳、市場跑腿、擺餐桌、資源回收、捉迷藏、後院尋寶。點畫面上的東西，藍色小狗就會跑過去幫忙拿、放、刷、煎。每關限時 3 分鐘，看能完成幾個；做錯只有溫和提示，不扣分。最佳紀錄只存在本機裝置。

| 關卡 | 玩法 | 計分 |
| --- | --- | --- |
| 香香蛋餅店 | 依序拿餅皮、雞蛋、蔥花放進鍋子，變金黃就翻面，再煎熟起鍋（太久會焦） | 煎好幾個蛋餅 |
| 洗碗小幫手 | 拿髒碗盤 → 放水槽 → 刷 4 下 → 按水龍頭沖水 → 放瀝水架 | 洗好幾個碗盤 |
| 客廳整理隊 | 撿起地上的東西，送進玩具箱／洗衣籃／垃圾桶 | 收好幾樣東西 |
| 市場跑腿趣 | 照清單拿 3 樣東西，拿齊去櫃台結帳 | 完成幾張清單 |
| 擺餐桌 | 看餐墊上淡淡的圖案，從櫃子拿盤子、碗、筷子、杯子擺上去，兩個座位都擺好算一桌 | 擺好幾桌 |
| 資源回收站 | 撿起地上的東西，分到紙類、塑膠類、鐵鋁罐、廚餘、一般垃圾 | 分對幾樣 |
| 捉迷藏 | 點家具找躲起來的妹妹；會偶爾露出尾巴，找錯兩次會聽到笑聲，錯三次出現箭頭 | 找到幾次 |
| 後院尋寶 | 看藏寶圖，點對的地方讓布麗挖；挖錯一次會出現箭頭 | 挖到幾個寶藏 |

線上版本：<https://freshrogerchang-dev.github.io/Bluey-game/>

網站由 GitHub Pages 直接從 `main` 分支根目錄發布。

## 啟動

在此資料夾執行：

```powershell
npm start
```

依終端機顯示的網址開啟。若只是快速查看，也可用任何靜態網站伺服器提供此資料夾。

## 測試

```powershell
npm test
```

## 程式結構

- `gameEngine.js`：八關的純規則（計時、計分、步驟判斷），有自動測試。
- `scene/stage.js`：three.js 舞台、點擊偵測、動畫與小狗角色。
- `scene/levels.js`：八個 3D 關卡場景。
- `vendor/three.module.min.js`：打包好的 three.js r186（MIT，見 `vendor/three.LICENSE`），離線也能玩。
